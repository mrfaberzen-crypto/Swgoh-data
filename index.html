Aurodium token priority

Grievous first, then Inquisitors

Use an eligible Attacker token on General Grievous: 2★/G1 → 6★/R5. B1, B2, MagnaGuard and Droideka are already R5, but need mods and an ability review. Tokens do not grant zetas. Preserve SLKR's zeta priority.

Second choice: Ninth Sister for a Tank token; Eighth Brother, then Second Sister for a further Attacker token; Seventh Sister for Healer; Fifth Brother for Support. Match the actual token role and in-game eligibility. Scout is deferred because the two troopers stay with Great Mothers.

Budget 3,500 Era currency per Aurodium token (7,000 for two), using your confirmed shop price. Carbonite is 1,000; it is not the default purchase. Never assume an unbought token is already owned.
